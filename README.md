# DevOps Quest

A hands-on DevOps course taught by building a small, original, Game Boy Advance-inspired browser game. We will make one change at a time, run it, inspect what happened, and debug intentional failures together.

The course's playable campaign map ([DEV-OPS QUEST: THE LINKED WORLD](https://devops-learning.history-atlas.workers.dev)) is hosted on Cloudflare Workers.

## How to play the course

- Start from what you already know about Linux; assume no other DevOps background.
- Each lesson adds one useful game feature and one real DevOps skill.
- You type and run the commands. I explain the new idea, then we check the result together.
- Keep each session focused and combine related steps so the course is useful without burning through usage on tiny exchanges.
- We keep the project local and free at first. Cloud accounts and paid services can wait.
- The result must be a proper playable browser game, not a terminal game, ROM, or emulator project. The terminal is our workshop; the browser is where you play.
- Aim for a Game Boy Advance-era feel, with original Zelda-like exploration and dungeon puzzles plus Metroid-like interconnected routes, map discovery, and ability-gated backtracking. Pokémon-style creature collecting and team battles are not the goal.

## Learner and teaching preferences

- Assume zero DevOps knowledge beyond Linux topics already discussed together.
- Teach interactively by making and playing a real game together, rather than presenting a long lecture or a pile of commands.
- Explain new terms in plain language, give a small concrete task, let the learner try it, and use the result or error as feedback.
- Build in visible, playable milestones. Explain what a command does before asking the learner to run it.
- Be accurate about what the learner actually did; for example, `curl` made an HTTP request, it did not ping the server, and no browser was used unless the learner says so.
- Keep the pace and answer size considerate of the user's limited five-hour usage allowance.

The course book — the campaign map, every chapter, and the progress scoreboard — is in [the Codex](book/README.md).
