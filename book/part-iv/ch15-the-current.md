# Chapter 15: The Current

> Part IV — The Cosmogony · DevOps skill: the full pipeline, end to end

## Goal
Ship a second tiny app through every chapter's tools on one real project.

## The idea
Everything so far is a muscle. This is the relay race: a brand-new, tiny application —
the assistant picks it, something with a real server and state — and runs it through the
whole gauntlet in order:
1. **Build** a small app (Ch 1, 3)
2. **Track** it in git (Ch 2)
3. **Debug** it when it fails, with processes and exit codes (Ch 4)
4. **Package** it in a container (Ch 5)
5. **Test** it and wire up CI (Ch 6)
6. **Deploy** it publicly with rollback (Ch 7)
7. **Operate** it: logs, secrets, backups (Ch 8)
8. **Observe** it with a dashboard and an alert (Ch 9)
9. **Defend** it: scan, headers, supply chain (Ch 10)
10. Practice its **outage** runbook (Ch 11)
11. **Rebuild** its infrastructure from code (Ch 12)
12. Give it **edge** state (Ch 13)
13. Run it in **Kubernetes** (Ch 14)

## Finish line
- One repo, one app, every chapter applied — each with a visible result.
- A postmortem-style write-up of what this course taught, in your own words.
